# 🐾 Kitty Kat vs. Mister Mouse: Moat Mayhem! 🐭

A 2D browser battle game where **Kitty Kat** fights **Mister Mouse** across a city moat! Built with pure Vanilla HTML5 Canvas, CSS3, and the Web Audio API—no external libraries or frameworks required.

## 🕹️ How to Play

### 💻 Desktop Controls
* 🐾 **Move**: Press `A` / `D` or `Arrow Keys`
* 🐟 **Throw Fish**: Press `Spacebar`
* 🌀 **Tail Whip & Deflect**: Press `T Key`

### 📱 Mobile Touch Controls
* 🐾 **Move**: Touch & Drag horizontally
* 🐟 **Throw Fish**: Tap Screen
* 🌀 **Tail Whip & Deflect**: Double-Tap Screen

---

## 🛠️ Tech Stack & Architecture

* **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3
* **Rendering**: Canvas 2D Context (`requestAnimationFrame` 60 FPS loop)
* **Audio**: Custom `SoundFX` synthesizer class via Web Audio API AudioContext
